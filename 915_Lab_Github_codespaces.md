# Lab_Create_a_Github_codespace

**THIS LAB IS OPTIONAL ITS A GOOD TRICK IN CASE YOU NEED A FREE LINUX MACHINE with internet access**

* go to a github url: (something like this)
* https://github.com/thyrs/Cloud-essentials---Omar-Dengo/blob/main/README.md (you need a github account)
* click on the upper left menu with 3 lines > terminal > New terminal (ctrl+shift+c)
* click on "Continue working in Github Codespaces"
* click on the first "VM" (virtual machine): 2 Cores, 8 GB RAM, 32GB storage
* click on trust folder and Continue
* this will launch a Workspace with a Ubuntu-linux terminal for the linx labs
